# Larkhaven (심밸리) — SillyTavern 확장

스타듀밸리와 심즈를 섞은 여성향 슬로우번 연애 시뮬. 상태창, 지도, 관계, 사교, 집 꾸미기, 캐릭터 추가를 담은 확장입니다.

## 설치

1. SillyTavern → 확장(Extensions) → **확장 설치(Install extension)** 에 이 저장소 주소를 붙여 넣습니다.
   `https://github.com/USERNAME/SillyTavern-Larkhaven`
2. `card/Larkhaven_card.json` 을 내려받아 캐릭터로 가져옵니다. 로어북은 카드 안에 들어 있으니, 내장 로어북 불러오기를 수락합니다.
3. 새 채팅을 열면 주민 등록 창이 뜹니다.

정규식 두 개(화면에서 `<delta>` 숨기기, 오래된 `<delta>` 를 프롬프트에서 정리)는 확장이 처음 켜질 때 정규식 목록에 자동으로 추가합니다.

## 알아 둘 점

- **태번헬퍼 스크립트 버전과 같이 켜지 마세요.** 둘이 같은 상태창을 그려서 충돌합니다. 확장을 쓰면 태번헬퍼의 Larkhaven 스크립트는 끄거나 지웁니다.
- 로어북은 한 번만 켭니다. `card/Larkhaven_lorebook.json` 은 카드 내장본과 같은 내용의 여분입니다.
- 주민 사진은 외부 이미지 호스팅에서 불러옵니다.
- 확장은 외부로 아무것도 보내지 않습니다. AI 프로필 생성 버튼만 지금 연결된 모델에 요청을 한 번 보냅니다.

## 업데이트

`manifest.json` 의 `auto_update` 가 켜져 있어, 저장소에 새 버전을 올리면 사용자 쪽에서 자동으로 받아 갑니다.
